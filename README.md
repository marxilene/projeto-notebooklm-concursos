
# Projeto NotebookLM – Como Estudar e Passar em Concursos Públicos

## 📚 Sobre o Projeto

Este projeto foi desenvolvido como parte do desafio da DIO utilizando o NotebookLM como ferramenta de aprendizagem ativa.

O tema escolhido foi **Como Estudar e Passar em Concursos Públicos**.

O objetivo foi organizar informações de diversas fontes, gerar resumos, criar mapas mentais, produzir áudios e vídeos e construir um material completo para revisão dos estudos.

---

# 🎯 Objetivos

- Aprender técnicas eficientes para concursos públicos.
- Organizar um plano de estudos.
- Criar materiais de revisão.
- Utilizar Inteligência Artificial como apoio aos estudos.
- Desenvolver um caderno temático utilizando o NotebookLM.

---

# 📖 Fontes Utilizadas

As fontes utilizadas foram adicionadas ao NotebookLM e serviram como base para a geração dos conteúdos.

Exemplos:

- PDFs sobre técnicas de estudo para concursos.
- Editais de concursos públicos.
- Materiais sobre planejamento de estudos.
- Conteúdos educacionais utilizados no NotebookLM.

---

# 🤖 Engenharia de Prompts

Durante o desenvolvimento foram utilizados diversos prompts, como:

- Como montar um cronograma de estudos?
- Como estudar para concursos trabalhando?
- Faça um resumo sobre técnicas de memorização.
- Crie um mapa mental sobre métodos de estudo.
- Gere perguntas para revisão.
- Explique o conteúdo como se eu fosse iniciante.

---

# ⚠ Dificuldades Encontradas

Em alguns momentos foi necessário reformular os prompts para obter respostas mais objetivas e organizadas.

Também foi necessário comparar diferentes respostas até encontrar a estrutura mais adequada para os estudos.

# 📖 Glossário

**Cronograma:** planejamento dos horários de estudo.

**Revisão Espaçada:** técnica para revisar conteúdos em intervalos de tempo.

**Mapa Mental:** representação visual dos principais conceitos.

**Prompt:** instrução enviada para a Inteligência Artificial.

**NotebookLM:** ferramenta de IA do Google voltada para estudos e organização de conhecimento.
